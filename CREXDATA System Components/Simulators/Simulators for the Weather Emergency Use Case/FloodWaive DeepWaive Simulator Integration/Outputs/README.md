# CREXDATA Flood Simulation Dataset

**Maximum Water Level Exports from FloodWaive Cloud Platform**

---

## About This Dataset

This dataset contains maximum water level rasters from flood simulations conducted using the FloodWaive Cloud Platform. Each simulation models surface water flow resulting from rainfall events, providing spatially-distributed flood depth data.

The data was generated for the CREXDATA project, covering urban areas in Germany and Austria.

---

## About FloodWaive

FloodWaive is a cloud-based flood simulation platform that combines high-resolution terrain data with physics-based hydrodynamic modeling to simulate pluvial (rainfall-driven) flooding. The platform enables:

- Rapid flood risk assessment for urban and rural areas
- Scenario analysis with different rainfall intensities and durations
- Evaluation of flood mitigation measures (terrain modifications, barriers, drainage)
- High-resolution output at 1-8 meter grid spacing

The underlying simulation engine solves the 2D shallow water equations to model water flow across complex terrain, accounting for buildings, streets, and other surface features.

## Data Format

### Maximum Water Levels (max_water_levels.tif)

- **Format:** GeoTIFF (Cloud Optimized)
- **Data Type:** Float32
- **Unit:** Meters (water depth above terrain)
- **NoData Value:** -9999.0
- **Compression:** DEFLATE
- **Coordinate System:** Local Transverse Mercator projection (see individual READMEs)

The raster represents the maximum water depth reached at each grid cell over the entire simulation duration. Values represent flood depth in meters above the ground surface.

---

## Selection Criteria

This export includes simulations meeting the following criteria:

- Simulation status: COMPLETE
- Rainfall duration: > 40 minutes
- Areas: CREXDATA project regions (Dortmund, Innsbruck)

---

## Usage Notes

- GeoTIFF files can be opened in any GIS software (QGIS, ArcGIS, etc.)
- Raster values of 0 indicate no flooding at that location
- Coordinate reference systems vary by area; check individual READMEs
- Resolution varies by simulation (1m, 2m, 4m, or 8m grid spacing)
