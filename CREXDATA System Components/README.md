# crexdata-public / CREXDATA System Components / README

This is the README file of the source code repository of the system components of the CREXDATA project (https://crexdata.eu/).

This repository has one folder per system component:

---

## Augmented Reality (AR)

This folder contains the source code of the system components for Augmented Reality (AR) and their integration into the overall CREXDATA system:

- Augmented Reality Components for Flood Visualization and Server (by TUC) for the Weather Emergency Use Case
- Augmented Reality Components for Firefighters (by TUC) for the Wildfire Use Case
- Mental Fatigue Eye Tracking Prediction System (by TUC) for Firefighters and Emergency Team Members
