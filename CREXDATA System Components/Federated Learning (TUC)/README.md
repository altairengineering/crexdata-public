This repository contains the Implementation of the Functional Dynamic Averaging (FDA) state-of-the-art meta-algorithm for extremely low-communication Federated Learning. Two versions of the FDA algorithm are included, the plain FDA with explicit tuning for hyperparameters, suitable for cross-silo training, and FedOPT,  which supports auto-tuning and is particularly efficient in cross-device settings. The suit also includes a module for rapid simulation of communication latency and throughput for Federated Learning training deployments on edge devices, using the NS3 simulator. The simulations can guide the low-cost deployment of federated learning processes.
