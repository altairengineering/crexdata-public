# crexdata-public / CREXDATA System Components / RapidMiner Extensions / README

This is the README file of the source code repository of RapidMiner Extensions (developed by Altair RapidMiner) for integrating various CREXDATA system components into the RapidMiner platform and the CREXDATA platform developed within the CREXDATA project (https://crexdata.eu/).

The subfolders of this folder contain the source code of the RapidMiner Extensions (JAR files) for integrating various CREXDATA system components, i.e. the custom operator definitions (CUSOP files) and the underlying RapidMiner processes specifying the execution logic of the custom operator(s) (RMP files).

This repository folder contains the following subfolders, one for each RapidMiner Extension:

---

## CEF: RapidMiner Extension for integrating the Complex Event Forecasting (CEF) component of the CREXDATA system

---

## Collision Avoidance: RapidMiner Extension for integrating the Collision Avoidance component of the CREXDATA system

---

## Data Integration Extensions: RapidMiner Extensions for integrating CRXDATA data source systems

- RapidMiner Extension for DRZ Drone Data Integration
- RapidMiner Extension for FMI Wave Height Forecasts 
- RapidMiner Extension for FMI Weather Forecasts 
- RapidMiner Extension for HYDS ARGOS Data Integration

---
