# crexdata-public / CREXDATA Use Case Scenarios / README

This is the README file of the source code repository of the use case scenario integration artefacts (source code, data processing workflows, etc.) of the CREXDATA project (https://crexdata.eu/).

The CREXDATA system components used for demonstrators of these use case scenarios can be found in this repository folder:
https://github.com/altairengineering/crexdata-public/tree/main/CREXDATA%20System%20Components

This use case repository has one subfolder per use case:

---

## Health Emergency Use Case

This folder contains the source code and integration artefacts for the health crisis use case, including the data processing workflows (RapidMiner processes) for this use case, integrating the use-case-specific simulators.

---

## Maritime Use Case

This folder contains the source code and integration artefacts for the maritime use case, including the data processing workflows (RapidMiner processes) for this use case, integrating the use-case-specific maritime simulators and collision prediction / avoidance service.

---

## Weather Emergency Use Case

This folder contains the source code and integration artefacts for the weather emergency use case, including the data processing workflows (RapidMiner processes) for this use case, integrating the use-case-specific simulators (DeepWaive FloodWaive flood simulator, wild fire simulator, Gazebo simulator, etc.).

---

The README files in the above folders describe the integration artefacts of the respective use case in more detail.
