# crexdata-public

This is the overall README file of the source code repository of the CREXDATA project (https://crexdata.eu/).

This repository is organized in two folders:
* CREXDATA System Components: This folder contains the source code of the system components and for their integration into the overall CREXDATA system.
* CREXDATA Use Case Scenarios: This folder contains the source code and overall processing workflows for the CREXDATA use case scenarios leveraging the above components.

The README files in the above folders describe the system components, their integration, and their use in more detail.

# License information
